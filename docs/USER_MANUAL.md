## 1. 安装与卸载

### 安装包安装（推荐）

1. 下载 `SubtitleStudioPro-<版本>-setup.exe`；
2. 双击运行，按向导完成安装（默认按当前用户安装，无需管理员权限）；
3. 安装程序会创建开始菜单快捷方式与桌面图标（可取消勾选）；
4. 可选勾选「关联字幕文件」：双击 `.srt` / `.ass` 等字幕文件即可直接打开本应用并导入字幕库。

### 卸载

开始菜单 → Subtitle Studio Pro → 卸载；或 Windows「设置 → 应用」中卸载。
卸载不删除你的历史记录与设置（存于 `文档\subtitle_studio\`），如需彻底清理请手动删除该目录。

### 便携版

解压 zip 到任意目录直接运行 exe。便携版不注册文件关联。

## 2. 环境依赖

本应用的视频处理通过外部工具完成，全部支持「自定义路径 / 捆绑版 / 应用内导入 / 系统 PATH」四级自动检测，检测成功的工具会在 **设置 → 环境依赖** 中显示实际使用的完整路径。

| 工具 | 用途 | 未安装时的影响 |
|---|---|---|
| **FFmpeg / FFprobe**（含 libass 的 full 版） | 字幕烧录、视频转码压缩、媒体信息探测 | 烧录与转码不可用 |
| **MKVToolNix** | 轨道提取（mkvextract）与封装（mkvmerge） | 轨道处理页不可用 |
| **Whisper**（openai-whisper / faster-whisper / whisper.cpp） | 语音转写生成字幕 | Whisper 字幕页不可用 |

配置方式（设置 → 环境依赖）：

- **FFmpeg**：填写 `ffmpeg.exe` / `ffprobe.exe` 完整路径，留空则自动查找；
- **MKVToolNix**：填写安装目录，或点「从安装目录导入」把工具复制进应用数据目录（便携化，换机免装）；
- **Whisper**：可填 `whisper.exe` / `python.exe` 或其所在目录；模型缓存目录默认 `~/.cache/whisper`。

FFmpeg 下载建议：[gyan.dev full 版](https://www.gyan.dev/ffmpeg/builds/)（含 libass，可烧录字幕）。
MKVToolNix 下载：[mkvtoolnix.download](https://mkvtoolnix.download/downloads.html)。
Whisper：`pip install -U openai-whisper`；提速可选 `pip install -U faster-whisper-ctranslate2`。

## 3. 快速上手：第一条流水线

以「一段生肉视频 + 一份外挂字幕 → 压好字的熟肉」为例：

1. **导入字幕**：左侧导航「字幕库」→ 拖入或点「导入」，选择 `.srt` / `.ass` 文件；
2. （可选）**翻译**：「AI 翻译」页配置 OpenAI 兼容 API 后批量翻译，时间轴与样式不动；
3. （可选）**转写**：没有现成字幕时，用「Whisper字幕」页从视频/音频直接生成；
4. **烧录**：「字幕烧录」页选择视频与字幕，选样式预设（白字黑边 / 经典黄字 / 大字描边，ASS 特效原样保留），加入队列；
5. **队列自动执行**：「任务队列」页查看实时进度，完成后可一键定位产物文件；
6. （可选）**封装**：「轨道处理 → 封装」页把字幕、音轨、字体附件打进 MKV 容器。

所有批量任务都进入统一队列：网络任务（AI 翻译）与本地任务（烧录/转码/封装）双车道并行，同车道内按顺序执行。

## 4. 功能页详解

### 字幕库
集中管理字幕文件：按时间轴排序、内容预览、SRT / ASS / SSA / VTT / SUB 互转，GBK / BIG5 编码自动检测并转 UTF-8。双击关联的字幕文件启动应用时自动导入本页。

### 字幕烧录
- 外挂字幕烧录（SRT 走 subtitles 滤镜 + 样式预设，ASS/SSA 走 libass 完整特效渲染）；
- 视频内嵌字幕轨烧录（自动预提取）；
- 可调编码参数：编码器（含 NVENC/AMF/QSV 硬件编码，自动检测可用性）、CRF、预设、分辨率、帧率、音轨；
- 自动匹配同目录同名字幕；字体目录可指定（配合轨道处理提取的字体附件）。

### 轨道处理
交互对齐 gMKVExtractGUI v2.15：
- **提取**页：MKV 的视频 / 音频 / 字幕 / 章节 / 字体附件全轨道提取，扩展名按 gMKVExtractGUI 规则生成（AVC→`.avc`、HEVC→`.hevc` 等），非 MKV/WebM 容器自动先无损转封再提取；
- **封装**页：字幕 + 音轨 + 字体附件封装为标准 MKV，轨道可勾选删减，GBK/BIG5 字幕自动预转 UTF-8。

### 转码压缩
FFmpeg 转封装 / 转码：分辨率、码率、CRF、x264 预设、帧率、音轨编码全部可调，参数可存为预设复用。

### AI 翻译
- 接入任意 OpenAI 兼容 API（OpenAI / DeepSeek / 中转站），只翻译文本、时间轴与样式标签原样不动；
- 设置页填好 Base URL 与 API Key 后可「获取模型」拉取列表下拉选择，「测试连接」一键验证配置；
- 实时直播：开始翻译后留在本页，下方「翻译进度」面板显示批次进度、思考流（DeepSeek R1 等推理模型）与逐批译文预览；
- 术语表 / 人名表锁定译法，支持 `.glossary.json` 旁车文件跨任务共享；
- 批间上下文保证前后文连贯；断点续传：失败批次重跑不重复计费已成功批次；
- 润色模式二阶段翻译（可加自定义指令），双语合并输出可选；
- 输出命名：`源文件名_语言码`（如 `demo_en.srt`）。

### Whisper 字幕
- 本地转写（不上传音视频）：openai-whisper / faster-whisper（CPU 约 4 倍速）/ whisper.cpp（实验性，检测到可执行才显示）三后端；
- GPU 自动推荐、VAD 静音过滤（faster 后端）、`{episode}` 提示词模板；
- 模型可预下载管理；转写结果实时输出可回看。

### 任务队列
双车道调度（网络/本地并行）、实时进度与日志、可取消、失败可重试并查看失败详情；托盘菜单可暂停/恢复整个队列。

### 历史记录
自动保存每次任务的完整参数与产物路径，可回溯重跑、在资源管理器中定位产物。

### 视频预览
内置播放器（libmpv）：播放列表、音轨 / 字幕轨切换、倍速、字幕样式实时调整、时间轴偏移。

## 5. 设置项说明

| 分组 | 内容 |
|---|---|
| **外观** | 主题模式（亮 / 暗 / 跟随系统）、种子色（内置预设 + 自定义色相） |
| **输出** | 全局默认输出目录、文件名模板（支持变量占位） |
| **环境依赖** | FFmpeg / MKVToolNix / Whisper 路径配置与检测状态（含实际使用路径） |
| **AI** | 翻译 API（Key / Base URL / 获取模型下拉选择 / 测试连接）、术语表、润色自定义指令 |
| **自动化** | 关闭窗口最小化到托盘；监视文件夹（目录出现「新视频 + 同名字幕」自动烧录，无人值守） |
| **维护** | 清理临时文件；导出调试包（日志 + 脱敏设置，反馈问题时使用） |

## 7. 自动更新

- 应用启动后会在后台静默检查 GitHub Releases；发现新版本时首页顶部出现提示条；
- 运行期间默认每 6 小时自动静默检查一次（可在设置页「维护 → 自动检查更新」关闭）；
- 设置页「维护 → 版本与更新」的「检查更新」可手动检查；发现新版本后展示 Release Notes，点「立即升级」自动下载安装包（显示进度）并以静默模式完成升级；
- 无网络或检查失败时静默跳过，不影响使用。

## 8. 常见问题

**Q：烧录时报「当前 FFmpeg 构建缺少 libass」？**
A：安装含 libass 的完整版 FFmpeg（如 gyan.dev full 版），并在设置中指定其路径。

**Q：轨道处理页提示未检测到 MKVToolNix？**
A：安装 MKVToolNix，或在设置 → 环境依赖中填写安装目录 / 使用「从安装目录导入」。

**Q：Whisper 检测很慢？**
A：首次检测需启动 Python 子进程（torch 导入 10~30 秒）。检测结果已持久化缓存，下次启动秒级恢复。

**Q：AI 翻译会泄露我的字幕吗？**
A：翻译时仅字幕文本发送到你自己配置的 API 端点（见[隐私声明](PRIVACY.md)），音视频文件永远不外发。

**Q：关闭窗口后任务还在跑吗？**
A：在。默认关闭最小化到系统托盘，任务后台继续；托盘菜单可暂停队列或真正退出。

**Q：双击 .srt 文件没反应 / 打开了别的程序？**
A：重新运行安装包勾选「关联字幕文件」，或在 Windows 设置中手动修改默认打开方式。

**Q：升级新版本会丢历史记录吗？**
A：不会。历史与设置存于用户文档目录，安装包升级原地覆盖程序文件。

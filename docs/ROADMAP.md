## 四、v1.2 —— 字幕工作流深化 ✅ 已完成（2026-08-20）

### 4.2 AI 翻译增强 ✅

| 项 | 内容 | 状态 |
|---|---|---|
| 术语表 / 人名表 | 词汇锁定（「本片中 Aria 不译」），随批次注入 prompt，上限 200 条，设置持久化 + 翻译页编辑对话框 | ✅ |
| 批间上下文携带 | 携带前批尾部 3 条「原文+译文」作为上下文，恢复 checkpoint 时自动衔接 | ✅ |
| 断点续传 | checkpoint 旁车 `.<输出名>.progress.json`（cueCount+mtime+lang 校验），失败/取消后重跑不重译已成功批次，成功即删 | ✅ |
| 译文润色模式 | 翻译后二阶段调用（仅断句/标点/口语优化，不改语义），翻译页开关默认关 | ✅ |

### 4.3 Whisper 转写加速 ✅

| 项 | 内容 | 状态 |
|---|---|---|
| faster-whisper 后端 | `whisper-ctranslate2` CLI 兼容接入；faster+CPU 用 `--compute_type int8`；设置页后端下拉（auto/openai/faster） | ✅ |

## 八、质量门禁（每个版本必须满足）

1. **静态检查**：`dart analyze` 零问题（info 也不留）。
2. **测试全绿**：`flutter test` 全量通过；新增行为必须有先失败的测试（TDD）。
3. **布局回归**：UI 改动在 800×600 / 1024×700 / 1280×800 三档窗口无 RenderFlex 溢出。
4. **命名规则**：新产物命名一律走「内存 used 集合 + 磁盘双查」去重，禁止模板外硬编码。
5. **依赖检测**：与外部工具可用性相关的 UI 一律 `ValueListenableBuilder` 监听，禁止静态读取。
6. **性能基准**：烧录/转码以 1080p 24min 样片为基准集，改动前后对比耗时与产物体积，防回归。

# Subtitle Studio Pro 隐私声明

> 适用版本：v2.1.0 ｜ 更新日期：2026-08-20

本声明说明 Subtitle Studio Pro（下称「本应用」）处理数据的全部场景。
**本应用不内置任何遥测、统计或崩溃上报服务**，以下为完整清单。

## 一、总原则

本应用的所有音视频与字幕处理（烧录、转码、轨道提取与封装、语音转写、
播放）均在**你的电脑本地**完成。默认状态下，本应用不向任何服务器发送数据。

## 二、主动外发的数据（仅以下两处）

### 1. AI 翻译（仅当你主动使用该功能）

| 项目 | 内容 |
|---|---|
| 发送内容 | **字幕文本**（按批次切分的台词原文）、术语表条目、系统提示词 |
| 发送目标 | 你在「设置 → AI」中自行配置的 API 端点（OpenAI / DeepSeek / 中转站等） |
| 触发时机 | 仅当你提交翻译任务时；不翻译不发送 |
| 音视频文件 | **永不外发**。Whisper 转写同样在本机执行 |

请注意：字幕文本将经过你所配置的第三方 API 服务商处理，其数据政策由该服务商
另行约束。涉及敏感内容的字幕请勿使用在线翻译。

### 2. 检查更新（联网查询版本号）

| 项目 | 内容 |
|---|---|
| 发送内容 | 一次标准的 HTTPS GET 请求（GitHub Releases API），**不携带任何个人信息、不携带文件** |
| 发送目标 | `api.github.com`（官方 API）与 `github.com`（下载安装包） |
| 触发时机 | 应用启动后自动检查一次 + 你在关于页手动点击「检查更新」 |
| 关闭方式 | 无法联网时自动静默跳过；不使用在线功能不受影响 |

## 三、本地存储的数据

存储位置：`文档\subtitle_studio\`（Hive 数据库 + 日志 + 导入的工具）。

| 数据 | 说明 |
|---|---|
| 应用设置 | 主题、输出目录、文件名模板、监视文件夹配置等 |
| **AI API Key** | **以明文保存在本机**，不会写入任何导出文件（见下） |
| 术语表 | 翻译术语 / 人名锁定表 |
| 历史记录 | 每次任务的参数与产物文件路径（含文件名） |
| 运行日志 | 结构化 JSON 日志（含任务执行参数、错误堆栈），自动轮转，保留最近若干份 |

上述数据仅存于本机，卸载应用不会自动删除；如需彻底清除，请手动删除该目录。

## 四、调试包（你主动导出时）

「设置 → 维护 → 导出调试包」会把近期日志与设置打包为 zip，用于问题反馈。
**导出前自动脱敏**：API Key 等敏感字段会被替换，不会进入调试包。
请你自行检查包内内容后再发给他人。

## 五、文件访问

- 文件关联：仅当你双击已关联的字幕文件时，读取该文件的路径并导入字幕库；
- 监视文件夹：仅在你明确配置并开启后，监听指定目录中的新增视频与字幕文件；
- 本应用不会扫描或上传上述目录之外的任何文件。

## 六、外部工具

FFmpeg、MKVToolNix、Whisper 均以本机子进程方式调用，处理过程不联网
（Whisper 模型首次下载除外，下载自官方源且仅模型文件）。

## 七、声明变更

功能变更涉及数据处理方式时，本声明将随版本更新同步修订。
